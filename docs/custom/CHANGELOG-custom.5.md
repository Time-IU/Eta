## 当前会话文字查找

- 聊天记录上方新增查找入口、逐处匹配计数、上一处／下一处、上下文高亮及原消息定位。
- 支持中英文、字面搜索和不区分大小写；匹配用户、助手及思考正文，不伪称检索图片或附件内部内容。
- 查询非空时顺序加载更早历史，直至完整当前会话；显示加载／等待／失败状态，失败须手动重试，避免把未加载完误报成无结果。
- 关闭或更换查询停止后续分页；已经发出的单页存储事务可能仍完成。会话切换使用现有 composition key 隔离。
- Markdown 暂不提供稳定字符坐标，因此长消息以固定栏中的精确高亮上下文保证命中可见，再跳到原消息并标记；不宣称字符级滚动。
- 搜索期间暂停自动跟底及旧页释放，不替换原正文渲染、长按菜单或选字实现。

## 模型菜单文字裁切

- 根因：COUI 原生菜单固定 40dp 行高、文字区域仅 24dp，却允许多行内容。
- 按实际字体及宽度测量能完整容纳时保留原生菜单；否则转入现有可搜索底部选择面板，避免破坏原生滑选命中几何。
- 模型／服务商名称在自有列表中自然换行，保留字体缩放；MIUIX 限高作用于滚动视口而非裁切整个弹层。
- 因此模型数不超过八个但名称太长／字体较大时，也可能打开底部面板。
