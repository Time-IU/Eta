# v3.4.4-custom.2 — 系统 TTS 操作区对齐

此为基于官方 v3.4.4 的非官方定制维护版；不代表上游作者背书。沿用 [custom.1 的功能范围及使用边界](CHANGELOG-3.4.4.md)，没有新增识别引擎或更换模型。

## 本次修改

- “打开系统文字转语音设置”和“重新检测”共用卡片内的操作区：左右各 20dp、上下各 12dp，按钮占满操作区可用宽度，标签居中，最小触控高度 48dp。
- 保留 COUI 与 Miuix 各自原生按钮、明暗主题和禁用状态。卡片左右留白一致，不再把内容自适应的小按钮直接贴在卡片左下角。
- 原来的系统设置跳转、保存中禁用、检测状态及重新检测回调保持不变；没有降低离线音色检查要求。
- 移除面向特定发布平台的介绍文档及当前文档索引，并清理既有 Release 说明里的对应链接。不重写旧提交或旧标签，以保留已发布 APK 对应的准确源码历史。

## 版本与验证方式

本版使用 Gradle 构建元数据 `-Peta.buildMetadata=custom.2`，APK 内显示 `3.4.4-debug+custom.2`，沿用上游 versionCode `2026111302`。源码版本基础仍为官方 v3.4.4，而不是官方新发版。

已通过完整应用构建、153 项选定回归测试（失败 0、跳过 0）、签名核验及设备端 ART 严格校验。签名后 APK 与本次构建的非签名内容逐项一致。验证摘要见 [validation-custom.2.json](validation-custom.2.json)；APK 大小和 SHA-256 同步列于本版 Release。未安装此构建进行 UI 实机验收。

本次改动范围是 UI 布局与文档清理。自动构建不能替代设备上明暗模式、大字号、窄屏、点击跳转和检测状态的视觉/交互验收；没有据此声称所有 ROM 均已通过。

## 安装提醒

覆盖安装前请先备份。包名仍为 `io.github.mangi.eta`，签名不是官方签名；同一历史定制证书才能作为相应覆盖更新使用。不要因签名冲突直接卸载日用版本。源码、必要构建材料与许可证见 [BUILD.md](../../BUILD.md) 和 [THIRD_PARTY.md](../../THIRD_PARTY.md)。
