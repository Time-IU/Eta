## 这次主要改什么

- 统一紧凑消息菜单、原位文字选取和独立朗读工具条，补齐草稿、返回键与界面生命周期处理。
- 在上游记忆和 Skills 机制上添加手动审核保存入口；区分原生会话分支与仅引用的新会话。
- 增加系统 TTS 适配及严格离线的消息朗读，LOCAL 入口集中展示六款本地语音识别模型。
- 完善采集侧停顿检测与电源键入口的部分 ROM 路由；不把“本地语音”等同于“整个助手离线”。

保留官方 3.4.4 的 DeepSeek ASR/TTS、凭据复用、侧边栏和依赖升级等既有更新；这些不属于定制版原创贡献。

## 使用边界与安装提醒

个人日用反馈良好，设备兼容未普验。Android 13+ / ARM64 是上游支持范围，不意味着本定制版已在所有这些设备验证。Root/LSPosed/OEM 电源入口需对应授权、模块激活和重启，仍受 ROM 限制；基础使用不因此被描述为必须 Root。

包名仍为 `io.github.mangi.eta`；定制签名不同于官方签名，不能据此承诺直接覆盖官方安装。同一已有定制证书只用于相应测试包签名，不代表官方签名。debug 包包含额外调试开销，体积较大。升级前自行备份并确认恢复方式；不要为绕过签名冲突贸然卸载，卸载可能丢失应用私有数据，未验证跨签名无损迁移。

模型不随 APK 内置。下载需要用户主动触发、网络及足够存储；安装后符合条件的 ASR 可离线运行，LLM/API 与在线语音服务仍按配置联网。没有静默切换云端的本地识别兜底。
