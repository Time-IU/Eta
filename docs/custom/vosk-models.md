## 安装格式与安全边界

- 接受官方原始 ZIP，不接受重打包 ZIP、任意下载 URL、解压目录、任意 Vosk 模型或修改过的权重。
- Vosk 网络请求严格匹配上述 HTTPS 官方 host、路径和固定文件名；不接受其他文件、子域、查询参数、端口、凭据或外站重定向。原六模型的固定 Hugging Face 来源及规则保持原样。
- 导入/下载先按目录限制原 ZIP 字节数并校验整包 SHA-256，再处理条目。仅允许目录内记录的路径与其祖先目录，拒绝绝对路径、`..`、反斜杠、空路径段、未知或重复条目、目录携带数据、既有输出及符号链接路径。
- 每个文件按预期字节数有界写入，在同一次解压写入中计算并验证 SHA-256，不再为解压哈希回读文件；至多 256 个 ZIP 条目、128 个有效文件、4,000,000,000 字节解压总量，当前两个模型的精确预期上限更小。不会把条目声明的任意路径直接用于输出。
- 内部解压布局为 `files/local_speech_models/<目录 ID>/vosk/`，保留官方 `am/`、`conf/`、`graph/`、`ivector/`、`rnnlm/` 等目录结构。
- 仅在本次新建暂存目录内操作，完整 SHA、目录树与许可检查通过后原子改名安装；已存在的安装目录即使损坏也不覆盖或删除。成功后删除本次暂存 ZIP，不删除用户选择的原始源文件。
- 安装仅保留一次落盘后的完整 SHA 校验，并核对校验前后指纹；原子改名后验证除安装根目录因 rename 变化的 ctime 外，安装根目录的设备/inode/大小/mtime 及所有 payload、子目录与元数据指纹保持一致，再缓存已安装身份。常规 inspect 与保存选择复用同一进程的完整校验证明，不重复扫描大文件；保存选择不再执行通用完成后的第二次 inspect。显式「重新检测（完整 SHA）」始终重新验证所有文件。新进程第一次加载同样全量验证；之后仅在文件树、路径、设备/inode、大小、纳秒 mtime/ctime 与安装标记全部不变时复用进程内验证缓存。不持久化跳过校验的标记；进程重启后重新全量验证。大模型安装仍有一次 2,143,476,709 字节的独立落盘校验（有意保留，不声称零读取）；安装后的常规 UI 检查不再增加同量级读取。

## 空间、内存与失败行为

ZIP 下载大小不等于解压存储，更不等于运行 RAM。安装前要求 ZIP 加解压文件合计空间，再加至少 16 MiB 安装元数据余量；文件系统还应留额外余量。大模型仅原包加解压文件就需 3,502,213,395 字节，不能将「1.3 GB 下载」宣传为「1.3 GB RAM」。

大模型官方定位服务器，可能需要数 GB 运行内存；本轮未测手机加载/流式识别速度、准确率或峰值 RAM，不作为低内存方案或默认推荐。内存不足、加载或识别失败应在本机明确报错，用户可手动改选已安装小模型；禁止自动联网识别或云端回退。

## 显式删除已安装权重

八款模型均提供独立删除入口，包括校验失败或损坏的模型；下载、导入与所有引擎保持可用。删除前弹窗显示精确模型名；仅删除该模型在应用内的已安装权重及关联安装元数据，不删除引擎或用户保留的原 ZIP / GGUF，之后可重新导入或下载。当前已保存选择不变，若删除正在选择的模型，必须重新安装或手动选择另一已安装模型后才能录音。

删除期间禁用设置操作与取消按钮，等待后端确认（最长约 90 秒）；服务会拒绝加载、录音或识别中删除。仅后端明确正常返回才报告删除成功，超时或 IPC 异常按结果未确认处理；无论成功失败均在不可取消的 IO finally 中强制完整 inspect 刷新，未安装状态本身不作为删除成功证据。
