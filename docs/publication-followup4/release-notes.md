# Eta 3.4.4 · followup4 整合测试版

非官方定制预发布，发布的是原始已签名 `Eta-v3.4.4-por-followup4.apk`，实际版本 `3.4.4-debug+integration-por.followup4`。沿用 custom.5 的 GitHub Pre-release 形式；**不包含后续 stage1–stage5 保功能替换候选代码或其测试结果**。

## 重点更新

- **会话和消息**：整合会话导航与全文查找，统一消息操作和原位选字；引用保留草稿，不自动发送。
- **设置与面板**：设置按功能归类，输入栏相关面板统一背景和关闭区；Eta 占用与上下文统计采用紧凑标签/数值及问号说明。
- **工具管理**：可用状态／模型可用范围双标签，保留两层限制、全局开关与白名单；提示词页移除重复入口。
- **后台画布**：整合原画布能力，保留设置与安全校验；调整读取／Hook 同步重试状态显示。
- **入口精简**：工作区功能、文件和菜单入口保留，移除重复顶栏图标与快捷手势；移除小白条快捷键及相关失效教学。
- **通知适配**：按本机框架实际通知资格选择格式；不等于保证所有 ROM 的流体云已显示。
- **保留语音**：沿用本机离线模型导入／删除、离线朗读等定制功能，不内置模型权重、不静默切换云端。
