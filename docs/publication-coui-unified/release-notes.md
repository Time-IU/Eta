## 重点更新

- **COUI多级页面统一**：共享二级／三级列表页和编辑页使用原生COUI骨架，协调顶栏、返回入口、背景、文字与分组间距，保留MIUIX。
- **设置分组精简**：Root与系统增强归入“工具”，不再独占一张卡；原功能和路由保留。
- **弹层风格协调**：23个旧弹窗调用文件接入主题感知宿主。COUI下输入栏面板、用量统计、Eta占用、保存记忆／技能及引用继续统一材质、圆角和操作区；不更改确认、保存、草稿或取消规则。
- **去掉无效切换**：“当前设备／全部能力”工具集合完全相同时隐藏重复切换；有差异的设备仍保留，未删除工具能力。
- **模糊与主题一致性**：COUI材质遵循同一偏好、系统支持和安全宿主门控；保留已有明暗主题选择和液态玻璃输入栏。COUI模态框使用宿主窗口背景源，不跨窗口复用坐标。
- 保留本地语音、模型导入／删除、工作区、权限与模型工具白名单，不清数据、不重置已有配置。
