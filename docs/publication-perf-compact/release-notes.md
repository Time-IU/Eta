# Eta 3.4.4 · Release 性能／精简测试版

基于已公开的 COUI 统一版，使用 **Release 优化构建**，保留现有功能与外观。本次仍标记为预发布测试版；“Release”指构建类型，不代表所有设备已验收。

## 重点更新

- **安装包缩减52.9%**：由COUI调试版59,687,777字节降至 **28,111,705字节（约28.1MB／26.81MiB）**。启用现有R8代码优化及资源裁剪，不删除语音引擎、COUI效果、工作区或权限功能来缩包。
- **减少流式Markdown重复工作**：仅合并显示端解析目标，按正文长度采用48／80／120ms节拍；首片及时显示，最终内容和关闭收口完整处理，不修改网络接收、历史消息或最终文本。
- **保留COUI统一体验**：沿用多级页面骨架、Root归组、弹层协调及能力筛选去重，MIUIX、液态玻璃输入栏和现有配置保持。
- **精简后专项保护**：保留JNI、Xposed及四个app_process入口。修复R8对归档依赖同步代码内联导致的ART锁验证软失败，仅限制TarUtils及两个相关Commons IO类的优化，其余优化继续启用。失败候选不作为本版附件。
